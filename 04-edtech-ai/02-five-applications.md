# 第 4 章｜教育 AI 五大應用（核心必背）

## 一句話重點

面試被問「AI 能怎麼用在你們產品？」就答這五塊。

---

## 應用 1：AI Tutor（AI 助教）

**做什麼：** 24 小時答疑、練習陪伴  
**怎麼做：** RAG 教材 + 引導式 Prompt + 對話記憶  
**成功標準：** 學生能「自己想出下一步」，不是抄答案  

設計原則（蘇格拉底式）：
```
學生：這題怎麼做？
AI：你覺得第一步該用哪個公式？為什麼？
（而不是直接貼完整解法）
```

風險：幻覺、洩題、養成依賴  

---

## 應用 2：Adaptive Learning（適性學習）

**做什麼：** 依程度動態調整內容與難度  
**核心引擎：** Knowledge Tracing（知識追蹤）  

簡化邏輯：
```
答對 → 該知識點掌握度 ↑
答錯 → 掌握度 ↓，推複習或補概念
掌握度達標 → 解鎖下一關（Mastery Learning）
```

面試可提演算法名：
- **BKT**（Bayesian Knowledge Tracing）經典  
- **DKT**（Deep Knowledge Tracing）深度學習版  

---

## 應用 3：Auto Assessment（自動評量）

| 題型 | AI 角色 |
|---|---|---|
| 選擇 / 填空 | 全自動批改 |
| 短答 | 語意比對 + 部分給分 |
| 作文 / 程式 | AI 初評 + 老師終審 |

重點：**高風險成績一定要人審**（公平、申訴、信任）

---

## 應用 4：Content Generation（內容生成）

老師輸入：單元目標 + 難度 + 題數  
AI 輸出：題目、解析、測驗、講義大綱、甚至影片腳本  

工作流：
```
生成 → 自動品質檢查 → 老師審核 → 進題庫
```

沒有審核就上架 = 教育事故。

---

## 應用 5：Learning Analytics（學習分析 / 預警）

看哪些訊號：
- 登入頻率、觀看完成率  
- 答題正確率、作答時間  
- 求助次數、重試次數  

產出：
- 學生弱點報告  
- 「可能掉班」預警名單  
- 老師介入建議  

B2B 超愛這個：可量化、可匯報給校長/機構。

---

## 把五個串成一個故事（面試超好用）

> 「學生晚上卡住 → AI 助教引導練習 → 系統更新知識掌握度 → 明天推適性題 → 老師早上看預警看板，對真正需要的人一對一介入。」

這就是 **AI 規模化一對一**。

---

## 小測驗

1. Adaptive Learning 的核心演算法概念叫什麼？  
2. 作文自動評分為什麼不能全自動定案？  
3. 用一句話串起五大應用。

<details>
<summary>參考答案</summary>

1. Knowledge Tracing（如 BKT / DKT）  
2. 公平、申訴、信度；高風險需人審  
3. 助教陪伴 → 掌握度更新 → 適性推題 → 內容補給 → 預警給老師  

</details>
