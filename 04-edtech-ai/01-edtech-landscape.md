# 第 4 章｜線上教學 × AI 產業地圖

## 一句話重點

教育 AI 的核心價值 = **個人化 + 自動化 + 數據洞察**，而且必須守住 **準確、公平、學術誠信**。

---

## 1. 為什麼 AI 適合教育？

傳統線上課痛點：

| 痛點 | AI 解法 |
|---|---|---|
| 所有人同一進度 | Adaptive Learning |
| 卡住沒人問 | AI Tutor 24hr |
| 老師改卷累 | Auto Grading |
| 不知道誰要掉隊 | Learning Analytics |
| 內容製作慢 | Content Generation |

---

## 2. 商業模式（面試加分）

| 模式 | 客戶 | 賣點 |
|---|---|---|
| B2C | 學生/家長 | 提分、陪讀、練習 |
| B2B | 學校/機構 | 減老師負擔、可量化成效 |
| B2B2C | 平台 + 老師 | 工具賦能內容創作者 |
| API / Platform | 其他 EdTech | 出題引擎、語音評測 API |

老闆愛聽的 ROI 語言：

> 「老師改卷時間降 X%、學生完課率升 Y%、預警介入後掉班率降 Z%。」

---

## 3. 標杆產品（做功課用）

| 產品 | 你要記得的點 |
|---|---|---|
| **Khanmigo** | 蘇格拉底式引導，不直接給答案 |
| **Duolingo** | 適性練習 + 遊戲化 + AI 練習 |
| **Coursera** | 大規模課程 + AI 輔助評分/內容 |
| **NotebookLM** | RAG 整理學習資料 |
| **MagicSchool 等** | 幫老師生成教案/素材 |
| **作業幫 / 猿輔導等** | 拍照搜題、華語市場路徑 |

面試話術：

> 「我特別認同 Khanmigo 的設計：AI 是引導者不是答案機。這對學習遷移與防作弊都關鍵。」

---

## 4. 產品能力地圖

```
學習者端                教師端                 平台端
─────────              ───────               ───────
AI 助教答疑             自動組卷               知識圖譜
適性練習               作文評語輔助            A/B 測試
錯題本 / 弱點分析       班級預警看板            內容審核
語音口說評測           教案生成               模型路由與成本
```

---

## 5. 不可碰的紅線（務必講）

1. **教錯** — 幻覺不可上線無審核  
2. **作弊** — AI 變成代寫工具  
3. **歧視** — 評分與推薦的偏見  
4. **隱私** — 未成年資料、學習紀錄  
5. **取代老師敘事** — 業界反感，也錯誤  

正確定位：

> 「AI 放大好老師的影響力，讓一對一體驗可以規模化。」

## 小測驗

1. 教育 AI 三大價值？  
2. B2B 客戶最常買的是什麼結果？  
3. 為什麼「AI 取代老師」是面試雷區？

<details>
<summary>參考答案</summary>

1. 個人化、自動化、數據洞察  
2. 減負 + 可量化學習成效 / 留存  
3. 忽略情感、動機、價值引導；也不符合產品倫理與銷售現實  

</details>
