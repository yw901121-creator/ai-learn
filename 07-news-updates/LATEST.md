## 今天你一定要知道的 5 件事

### 1) OpenAI 推出 GPT-5.6 家族（Sol / Terra / Luna）
- **是什麼：** 不再只丟一個旗艦，而是三層級產品線  
  - **Sol**＝旗艦最強  
  - **Terra**＝日常均衡  
  - **Luna**＝最快最便宜  
- **新概念：** `ultra` 模式 —— 多 Agent 平行協作打硬仗  
- **面試怎麼說：**  
  > 「現在大廠用模型分層與路由控制成本，教育平台高流量答疑走平價層，難題解析走旗艦層。」

### 2) Anthropic：Claude Fable 5 留在付費方案
- Fable 5 持續作為 Anthropic 高階能力模型  
- 不同方案額度/計費方式不同（Max/Premium 與 Pro 有別）  
- **面試怎麼說：** 旗艦模型常有容量與成本管理，產品要做 fallback。

### 3) Moonshot 發布 Kimi K3（超大開源取向）
- 宣稱約 **2.8T** 參數級、長上下文、原生視覺  
- 權重預計後續開放（關注 7/27 左右動向）  
- **意義：** 中美開源/閉源競爭加劇，企業多了私有化選項

### 4) 阿里 Qwen3.8 預覽
- 同樣走高能力 + 即將開權重路線  
- **對你的意義：** 面試可提「會評估開源模型做私有部署的可行性」

### 5) 架構主流詞不變但更成熟：RAG + MCP + Agent
- RAG＝知識  
- MCP＝工具連接標準  
- Agent＝執行  
- 教育論文/產品也在把這三者做成智慧家教系統

## 本週新術語（請背）

| 新詞 | 意思 | 什麼時候用 |
|---|---|---|
| **Model Tiering** | 模型分層（旗艦/均衡/便宜） | 講成本與路由 |
| **ultra（OpenAI）** | 多 Agent 平行加速模式 | 講 Agentic 能力 |
| **Open-weight** | 開放模型權重（可自行部署） | 講開源策略 |
| **Long-horizon Agent** | 能撐很長多步任務的 Agent | 講複雜工作流 |
| **Computer Use** | AI 操作電腦介面 | 講數位員工 |

## 對「教育 AI 面試」的影響（重點）

1. **別再只說 GPT** —— 要能比較多家與開源  
2. **會講路由** —— 不同教學任務用不同模型層級  
3. **會講可控** —— Agent 越強，越要權限與審計  
4. **會講開源選項** —— 學校客戶常問資料是否出境
