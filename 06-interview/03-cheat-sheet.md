# 口袋小抄（面試前 10 分鐘）

## 30 秒開場
AI × 教育＝個人化 + 自動化 + 數據洞察；LLM + RAG + Agent；AI 加速老師不取代。

## 必背對照
| 詞 | 一句話 |
|---|---|
| LLM | 大語言模型，生成文字/code |
| RAG | 先查教材再回答 |
| OCR | 圖片/掃描件抽文字 |
| Agent | 規劃並呼叫工具做事 |
| Agent Loop | 感知→規劃→行動→觀察→反思 |
| Harness | 包住模型的執行框架（工具/權限/記憶） |
| Skills | 可重用、按需載入的專業能力包 |
| Context Compact | 壓縮舊上下文，騰給新資訊 |
| Lost in the Middle | 長上下文中段易被忽略 |
| MCP | AI 接工具的標準插頭 |
| Hallucination | 幻覺，教錯最致命 |
| Knowledge Tracing | 追蹤知識點掌握度 |
| Adaptive Learning | 依程度動態調內容 |
| Guardrails | 安全護欄與權限 |

## 上下文怎麼讓 AI「注意重點」
1. 釘選規則（Pin）  
2. 狀態卡（goal/constraints/progress）  
3. RAG 叮放 Top 精煉證據  
4. 關鍵指令放**開頭 + 結尾**  
5. 舊輪次做 Compact，不要 20 輪全文硬塞

## 五大應用
助教、適性學習、自動評量、內容生成、學習預警

## 風險四件套
教錯 / 作弊 / 偏見 / 隱私

## 2026-07 模型速記
GPT-5.6（Sol/Terra/Luna）・Claude Fable 5 / Sonnet 5・Gemini 3.5・Kimi K3・Qwen3.8

## 金句
1. AI 讓一對一可以規模化  
2. 引導 > 直接給答案  
3. 練習可開 AI，考試要關  
4. 關鍵成績 Human-in-the-loop  
5. 選模型看準確・成本・延遲・可控  
6. 塞得進 ≠ 用得好（Lost in the Middle）  
7. 模型是大腦，Harness 才是能上線的身體
