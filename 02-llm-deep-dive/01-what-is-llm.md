# 第 2 章｜什麼是 LLM？

## 一句話重點

**LLM = Large Language Model（大語言模型）**  
用海量文字訓練，擅長理解與生成自然語言（以及程式碼）。

---

## 1. LLM 在做什麼？

本質上：預測「下一個最可能的 token」。  
聽起來簡單，但規模夠大 + 對齊做好之後，表現出：

- 翻譯、摘要、寫作
- 寫程式、除錯
- 推理、規劃（尤其 reasoning / thinking 模式）
- 多輪對話

---

## 2. 2026 年主流模型家族（必記）

| 公司 | 旗艦 / 主力 | 定位（面試說法） |
|---|---|---|
| **OpenAI** | GPT-5.6 家族（Sol / Terra / Luna） | 三層級：旗艦、日常、高性價比 |
| **Anthropic** | Claude Fable 5、Claude Sonnet 5 | 長任務、寫 code、專業工作 |
| **Google** | Gemini 3.5（Flash 等） | 多模態、快速、agentic |
| **Moonshot** | Kimi K3 | 超大開源路線、長上下文 |
| **Alibaba** | Qwen3.8（預覽） | 開源權重、性價比競爭 |
| **Cursor 等工具** | Composer 等 | IDE / Agent 產品內建模型 |

> 數字會變。面試重點不是背版本號，而是：**知道多家競品、知道要分旗艦/性價比層級、知道開源 vs 閉源。**

---

## 3. 閉源 vs 開源

| | 閉源（GPT、Claude） | 開源/開權重（Llama、Kimi、Qwen） |
|---|---|---|
| 優點 | 通常更強、維護好、API 方便 | 可私有部署、可控、成本彈性 |
| 缺點 | 資料出公司、價格、依賴供應商 | 要自己維運、安全與品質自負 |
| 教育公司常見選法 | SaaS 快速上線 | 有資安/在地化需求時私有化 |

---

## 4. Reasoning / Thinking Model（2025–2026 熱詞）

有些模型會「先想再答」（內部多步推理）：

- 適合：難題、數學、複雜 code、規劃
- 代價：更慢、更貴（token 更多）

面試說法：

> 「簡單任務用快模型；複雜推理用 thinking 模式，在成本與品質間取捨。」

---

## 5. 教育場景怎麼選模型？

| 場景 | 優先考量 |
|---|---|
| AI 助教答疑 | 準確性、可引用教材、延遲 |
| 自動出題 | 結構化輸出、可控難度 |
| 作文評語 | 語氣、公平性、可解釋 |
| 批次改作業 | 成本（高流量） |
| 研究型 Agent | 工具調用、長任務穩定性 |
